# CIRA-Boulder Data Assimilation GitHub Pages Site

Static website intended for GitHub Pages.

## Files
- `index.html` — Home
- `news.html` — News index
- `news/` — Individual news posts
- `publications.html` — Publications and presentations
- `projects.html` — Project landing page
- `da-projects-2024-2029.html` — Cooperative-agreement DA projects
- `standalone-projects.html` — Standalone projects
- `style.css` — Shared site styling
- `figures/` — Images and figures

## GitHub Pages
Upload these files to the repository root. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, and save.
