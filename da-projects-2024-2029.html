Data Assimilation Project

Funding AgencyNOAA Project NumberNA24OARX432C0007-T3-01S005 Project PILiaofan Lin Performance Period2024–2029

This project is conducted under the cooperative agreement between CIRA and NOAA/OAR/GSL. Specific tasks and sub-projects supported through this account vary by fiscal year depending on research priorities and funding availability.

The proposed data assimilation research is organized around three core objectives with strong heritage at CIRA: (1) satellite data assimilation and observing-system impact assessment; (2) coupled data assimilation; and (3) development and assessment of high-impact weather applications. Past and current sub-projects are summarized below.

Assimilation and Verification for Atmospheric Rivers, Water in the West

Project LeadKeenan Eure Funded Period2025–2027

Description: CIRA-Boulder supports the development and verification of prototype MPAS-based atmospheric river (MPAS-AR) forecast systems, with an emphasis on advancing JEDI-based cycled data assimilation capabilities. Key activities include improving the assimilation of atmospheric motion vectors (AMVs), evaluating their impacts through retrospective and/or real-time experiments, and potentially exploring the assimilation of radio occultation observations. These efforts leverage and contribute to ongoing RRFSv2 data assimilation development to improve atmospheric river prediction.

JEDI/MPAS-Based Rapid-Update Assimilation Tests in Support of Future GeoXO Sounder Deployments

Project LeadLiaofan Lin Funded Period2024–2027

Description: The GeoXO project supports development of data assimilation and diagnostic capabilities for future geostationary hyperspectral infrared sounder observations. Current work focuses on developing observation-impact diagnostics for MPAS-JEDI and applying them to evaluate MTG-IRS observations as a proxy for future GeoXO sounder data, along with conventional and other satellite observations, in single-cycle and retrospective data assimilation experiments.

JPSS Data Assimilation Research and Development

Project LeadKeenan Eure Funded Period2024–2027

Description: The JPSS project supports the development and evaluation of satellite radiance data assimilation capabilities for NOAA's next-generation Rapid Refresh Forecast System (RRFSv2) using MPAS-JEDI. Current work focuses on evaluating the impacts of JPSS ATMS and CrIS radiances and Tomorrow.io Microwave Sounder (TMS) observations, improving all-sky radiance assimilation and observation-error treatments, and incorporating direct broadcast satellite data into RRFSv2 for real-time and retrospective experiments.

AI/ML Techniques for Data Assimilation Applications

Project LeadsAngie Burke, Alex Schein, Liaofan Lin Funded Period2025–2027

Description: The AI/ML Techniques for Data Assimilation Applications project supports the development and evaluation of machine learning (ML) approaches for weather analysis and data assimilation. Current work focuses on developing ML-based Real-Time Mesoscale Analysis (RTMA) using the ADAF framework to incorporate observations and model backgrounds, as well as improving radar radial velocity dealiasing using ML techniques. These efforts aim to enhance traditional data assimilation capabilities and explore ML-based alternatives for NOAA's Real-Time Mesoscale Analysis (RTMA) and next-generation Rapid Refresh Forecast System (RRFS).

GSL JEDI Developments

Funded Period2026–2027

Description: The GSL JEDI Developments project supports advancements in data assimilation capabilities using the Joint Effort for Data assimilation Integration (JEDI) framework to improve short-range weather prediction in NOAA's next-generation Rapid Refresh Forecast System (RRFS). Current work focuses on developing coupled land-atmosphere assimilation, advancing aerosol data assimilation using MPAS-JEDI, and improving verification and diagnostic capabilities. These efforts aim to enhance weather analyses and forecasts, particularly for hazardous weather conditions, including severe convection, heavy precipitation, and air quality.

RRFS Data Assimilation Advancements

Funded Period2026–2027

Description: The RRFS Data Assimilation Advancements project supports the development, testing, and evaluation of data assimilation capabilities for NOAA's next-generation Rapid Refresh Forecast System (RRFSv2) using MPAS-JEDI. Current work focuses on improving land and near-surface data assimilation, advancing aerosol and lightning data assimilation, and enhancing ensemble cycling strategies. These efforts also include developing monitoring and diagnostic tools, conducting real-time and retrospective experiments, and evaluating analysis and forecast performance to improve short-range and hazardous weather prediction.

Assimilation for Aviation Applications

Funded Period2024-2026

Description: The Assimilation for Aviation Applications project supported the development and evaluation of data assimilation techniques to improve short-range weather analyses and forecasts relevant to aviation. The work focused on adapting JEDI lightning data assimilation capabilities for the MPAS-based Rapid Refresh Forecast System (RRFS) and conducting sensitivity tests to optimize the horizontal integration area used by the lightning observation operator for the MPAS grid. These efforts aimed to improve the assimilation of lightning observations and support better forecasts of convective weather.
